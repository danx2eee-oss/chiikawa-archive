# 치이카와 아카이브 (공동 열람, 관리자 수동 등록)

## 기능
- 모든 방문자는 회원가입 없이 게시글 목록 열람
- 게시글은 원본 X 공식 임베드(이미지 주소를 별도 제공한 경우 직접 이미지 표시)
- 각 방문자의 책갈피와 읽던 위치는 본인 브라우저 localStorage에만 저장
- 게시글은 관리자 도구(admin.html)에서 작성하고 posts.json을 다운로드한 다음 GitHub에 수동 반영
- 별도의 유료 서버/API 없음

## 공개 방법
1. GitHub 저장소 `danx2eee-oss/chiikawa-archive`에 이 폴더 **안의 파일과 data 폴더**를 업로드한다. `index.html`, `admin.html`, `data/posts.json`이 저장소 최상단에 있어야 한다.
2. GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
3. 배포 주소: https://danx2eee-oss.github.io/chiikawa-archive/

## 게시글 추가
1. 배포 사이트의 `관리자 도구`를 열어 `현재 공개 데이터 불러오기` 클릭.
2. X 게시글 링크와 게시 날짜를 입력하고 `게시글 추가` 클릭. 원본 게시글에서 실제 날짜를 확인할 것.
3. `posts.json 다운로드` 클릭.
4. GitHub 저장소 `data/posts.json` 파일 화면에서 편집(연필 아이콘)하거나 `Add file → Upload files`로 해당 파일을 교체하고 커밋한다. GitHub 모바일 웹에서 메뉴가 보이지 않으면 브라우저 데스크톱 사이트 보기를 사용한다.
5. Pages 반영 후 다른 사람도 게시글을 볼 수 있다.

## 주의
- `admin.html`은 비밀번호로 보호되지 않는다. 누구나 열 수 있지만, 저장소에 쓰기 권한이 없으면 공개 데이터를 수정할 수 없다. 관리자 도구에서의 변경은 브라우저 초안에만 반영된다.
- GitHub Pages는 공개 사이트다. 비공개 자료, X 로그인 쿠키, 액세스 토큰 등을 올리지 말 것.
- X의 공식 임베드 스크립트는 X가 허용하는 방식으로만 사용하며, 원본이 삭제·비공개·제한되면 표시되지 않을 수 있다.
- X 게시글을 자동 수집하지 않는다. 게시글 날짜와 이미지 유무는 수동 입력이 필요할 수 있다.
- 이미지 필터는 `images` 필드에 이미지 URL을 입력한 게시글만 인식한다. X 공식 임베드 안에만 있는 이미지는 필터가 인식하지 못한다.
- 공개된 타인의 이미지 파일을 저장소에 재업로드하지 않는 것을 권장한다.
- 사용자 책갈피는 브라우저별로 별개이며, 브라우저 데이터 삭제 시 사라질 수 있으니 백업한다.
